# Barber Booking

Applicazione web per un salone di barbiere/parrucchiere: prenotazione online dei servizi, vendita di prodotti con ritiro in negozio, gestione del salone e statistiche. Sviluppata come progetto finale del corso Full Stack Python.

> Stato: in sviluppo (progettazione completata, inizio dell'implementazione).

## Tecnologie

- Python 3, Flask, Jinja
- MySQL (driver `mysql-connector-python`)
- HTML, CSS, JavaScript

## Installazione (Windows, PowerShell)

```powershell
git clone <URL-del-repository>
cd barber-booking
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
