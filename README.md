# Barber Booking

Applicazione web per la prenotazione online di un salone di barbiere/parrucchiere, sviluppata come progetto finale del corso Full Stack Python.

> Stato: in sviluppo (fase 1 – setup).

## Tecnologie

- Python 3, Flask, Jinja
- MySQL (driver `mysql-connector-python`)
- HTML, CSS, JavaScript

## Installazione (Windows, PowerShell)

```powershell
git clone <URL-del-repository>
cd barber-booking
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
